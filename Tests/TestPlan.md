# 1. Введение

Данный документ описывает план тестирования веб-приложения JokeHub.

JokeHub представляет собой веб-сервис и Telegram-бот для просмотра, поиска, публикации и фильтрации анекдотов. Пользователи могут просматривать анекдоты, искать их по тегам и тексту, добавлять собственные анекдоты, а модераторы — редактировать и удалять контент.

Цель тестирования — проверить соответствие системы функциональным и нефункциональным требованиям, описанным в SRS, а также убедиться в корректной работе основных компонентов приложения.

---

# 2. Объект тестирования

Объектом тестирования является система JokeHub, включающая следующие компоненты:

- веб-интерфейс на FastAPI;
- систему авторизации и регистрации пользователей;
- модуль хранения данных PostgreSQL;
- систему тегов и поиска анекдотов;
- Telegram-бота;
- модуль автоматической генерации тегов;
- систему модерации анекдотов;
- API для динамической загрузки анекдотов.

# 3. Атрибуты качества

## Функциональная пригодность

- функциональная полнота: приложение должно выполнять все заявленные функции;
- функциональная корректность: приложение должно выполнять все заявленные функции корректно;
- функциональная целесообразность: отсутствуют не заявленные функции, которые бы мешали приложению выполнять первоначально поставленные задачи.

## Удобство использования

- понятность интерфейса;
- простота навигации;
- защита от ошибок пользователя.

## Надёжность

- устойчивость к ошибкам;
- корректная обработка исключений.

# 4. Риски

К возможным рискам относятся:

- недоступность PostgreSQL-сервера;
- проблемы с Telegram API;
- высокая нагрузка на сервер при обработке большого количества анекдотов;
- ошибки при генерации векторов сравнения;
- повреждение данных при автоматической обработке тегов;
- медленная работа полнотекстового поиска.

---

# 5. Аспекты тестирования

## Согласно функциональным требованиям

### 5.1 Регистрация пользователя

Варианты:

- корректные логин и пароль;
- пользователь уже существует;
- пустые поля.

---

### 5.2 Авторизация пользователя

Варианты:

- корректный логин и пароль;
- неверный пароль;
- несуществующий пользователь.

---

### 5.3 Просмотр анекдотов

Варианты:

- просмотр главной страницы;
- бесконечная прокрутка;
- отсутствие анекдотов;
- сортировка анекдотов.

---

### 5.4 Поиск анекдотов

Варианты:

- поиск по тексту;
- поиск по тегу;
- поиск по несуществующему тегу;
- пустой запрос;
- поиск спецсимволов.

---

### 5.5 Фильтрация анекдотов

Варианты:

- фильтрация по дате;
- фильтрация по тегу;
- комбинированная фильтрация;
- фильтрация без результатов.

---

### 5.6 Добавление анекдота

Варианты:

- корректное добавление;
- пустой текст;
- добавление без авторизации;
- добавление длинного текста.

---

### 5.7 Telegram-бот

Варианты:

- команда `/start`;
- команда `/random`;
- поиск анекдотов по тегу;
- неизвестная команда;
- отсутствие найденных анекдотов.

---
